# 信号旗（Shingoki）

一条环线谜题：在格心之间画线，连成**一条**经过所有圆点的闭合回路。黑圆处必须转弯，白圆处必须直行，圆里的数字是从该圆沿回路向两侧走到各自**第一次转弯**处的长度之和。

- 纯前端（Vite + TypeScript + SVG），无框架、无外部资源，音效/特效全部程序合成
- 鼠标 + 键盘双输入、撤销/重做、实时校验与错误高亮、提示一格、显示解
- 规则推理「逻辑解题」回放，内置 6 道唯一解、可纯规则推完的题
- 自定义题板（最多 20×20）：调色板放黑圆/白圆与数字，保存 / 编辑 / 删除

## 规则

1. 在上下/左右相邻两个格子的**格心之间**画线段，所有线段连成一条闭合回路；
2. 回路不自交、不分叉（每个格心要么不经过，要么恰好接两条线）；
3. 回路必须经过棋盘上**所有**圆点；
4. **黑圆**：回路在此 90° 转弯（一横一竖）；
5. **白圆**：回路在此直行（左右贯通或上下贯通）；
6. **数字 N**（1–99，圆里也可以没有数字）：从该圆沿回路向两侧走，各自遇到的第一个转弯处为止的长度之和 = N。
   长度按跨过的格数计（紧邻的转弯算 1），途中经过其它圆点**不停止计数**；
7. 每道题都有唯一解。

## 自定义题板

1. 点「自定义」，设置宽高（4×4 ~ 20×20），点「生成网格」；
2. 在调色板里选「黑圆 / 白圆 + 数字」画笔，点格子放置；同一格再点一次清除，右键也可清除；
   键盘 <kbd>1</kbd>–<kbd>9</kbd> 直接在当前格填黑圆数字（当前格是白圆时保留白色），<kbd>0</kbd> / <kbd>退格</kbd> 清除；
   调色板/键盘提供 1–9，题面编码本身支持 0–99（图片导入的两位数会在棋盘与编辑器里正常显示）；
3. 「载入题板」立即开始玩并存入题库；「保存到题库」只保存；「求解」会用回溯求解器求一组解并做唯一解校验
   （状态栏/消息区会显示「唯一解 / 有 N 个解 / 无解 / 超时」）；
   已保存的自定义题在左侧列表里可以「编辑」（题面会还原到编辑器，保存会覆盖原题）或两次点击「×」删除。

自定义题只要求能解，不强制唯一解；「求解」会顺带报告解的个数，想确认唯一性看那里的提示即可。

## 启动

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5216
```

端口 5216 固定在 `package.json` 的 `puzzle.port`（`vite.config.ts` / `scripts/*` 都从这里读）。

其它脚本：

```bash
npm run build      # tsc 类型检查 + vite 生产构建到 dist/
npm run check      # 题库审计：参考解合法 / 解唯一 / 逻辑纯推 / 编解码 round-trip（含 0–99 圆编码自检）
npm run gen        # 重新生成内置题库（随机种子固定，结果可复现）
npm start          # 开发服务器（scripts/dev.mjs，自动打开浏览器）
npm run verify     # Playwright（Edge）实测：内置题 / 鼠标 / 键盘 / 自定义题增删改
```

`npm run verify` 需要先启动开发服务器，并已安装 Edge（默认路径
`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`，可用环境变量 `EDGE_PATH` 覆盖）。
截图输出到 `output/playwright/`。

开发期还可以访问 `http://127.0.0.1:5216/__audit` 在浏览器里跑一遍题板审计。

## 实现思路

- **棋盘模型**：圆在格子里，回路走「格心到格心」的正交线段，因此每条候选边就是
  `core/board.ts` 里的标准边（先水平 `h*(w-1)` 条、再竖直 `(h-1)*w` 条），可直接复用
  `edgeAtPoint` 命中和 edge 模式的交互约定。
- **校验**：先算每个格心的度数（只能 0 或 2），再判圆的转弯/直行，再沿回路走两臂核对数字，
  最后用连通分量数确认是「唯一一条闭环」。错误格、断路端点、分叉、圆方向/数字错误都会高亮。
- **逻辑推理**：规则传播到不动点（含「已闭环则其余边全排除」、数字两臂下界和 = N 时强制转弯等），
  推不动时用反证法（假设一条边，传播出矛盾则取反）继续；仍推不完才退回求解器补全并标记 `saturated=false`。
  内置题全部是「纯规则推完」。
- **生成器**：在对偶网格上随机长无洞、无捏合的多联骨牌，其边界即闭环；再按拐角/直行挑圆、
  由回路算数字，逐步加线索直到「解唯一 + 逻辑纯推」。
- **自定义题板**：复用 core 的 `cell` 模式，圆编码同时兼容两段：
  旧紧凑编码 `10+n` / `20+n`（n = 0..9，旧题库/旧存档逐字节不变），
  以及数字 ≥10 时才使用的扩展编码 `100+n` / `200+n`（n = 0..99）；
  为 `CustomSupport` 增加了通用 `palette`（调色板画笔）能力，`keyForDigit` 可读到当前格值。
- **题面 board 串**：只有题面里出现 ≥10 的数字时才从「每格 1 个 base36 字符」的旧紧凑格式
  切换成「每格 2 个 base36 字符」的宽格式；解码按字符串长度自动识别，所以旧题库完全不用改。
- **两位数字**：规则/校验/求解只读 `circleColor` + `circleNumber`，与数字位数无关，
  两位数线索会自然参与两臂求和、下界/上界推理与回溯求解；渲染对 ≥10 的圆用略小字号。

## 已知限制

- 键盘光标在横边/竖边之间切换是「垂直方向键切到最近另一种边」，不是四向连续网格，习惯后很快；
- 自定义题板不强制唯一解，20×20 大盘的「求解」可能超时（会提示），逻辑回放对超大自定义题也会先跑规则再看是否需要回溯；
- 自定义题板调色板/键盘只提供 1–9（题面编码与图片导入支持 0–99，两位数可正常渲染/校验/求解，但还没有手工输入两位数的 UI）；
- 内置题由生成器生成，线索密度偏高，难度区分主要靠盘面尺寸（生成器也仍只产出 2–9 数字的线索）；
- 音效依赖浏览器 Web Audio，自动播放策略下需先点一下页面。

## 从图片导入题库（自动识图）

```bash
node scripts/import-image.mjs month.png                     # 只预览识别结果，不写入
node scripts/import-image.mjs month.png --append            # 追加到 src/game/puzzles-data.ts
node scripts/import-image.mjs month.png --append --verify   # 顺带校验唯一解并写入参考解
```

- 用 Playwright + Edge 无头浏览器读像素：全图连通域区分"格心圆点 / 黑圆 / 白圆"→ 聚类圆点得到网格 → 圆内像素按黑圆取白字、白圆取黑字 → 字体模板自动择优 + 字形簇识别数字。
- 常用选项：`--name`、`--series`、`--width N --height N`（自动识别网格失败时手动指定）、`--map 0=3,1=2`（人工指定字形簇对应的数字）、`--dry`、`--debug <目录>`、`--max-nodes`、`--verify-timeout`。
- 圆内数字支持 0–99：0–9 仍按旧的紧凑编码 `10+n` / `20+n` 写入，10–99 自动改用扩展编码 `100+n` / `200+n`；
  题面 `board` 串在出现 ≥10 的数字时切换成每格 2 个 base36 字符的宽格式，旧题库仍是每格 1 字符，互不影响。
  因此像 month.png 里的 10 / 14 / 25 会作为线索完整保留，不再丢线索。
- `--drop-large` 已废弃（仅为兼容保留，传入会被忽略）：新的两位数字编码不再需要丢弃 >9 的线索。
- `--verify` 在子进程里调用项目求解器，超时或崩溃只警告，此时条目不写参考解。
